# svg-examples

This repository contains files mentioned in [RFC 7996](https://www.rfc-editor.org/info/rfc7996) (which was obsoleted by [RFC 9896](https://www.rfc-editor.org/info/rfc9896)).

For current guidance on diagrams, please see https://authors.ietf.org/diagrams.

(If you are seeking the Internet-Draft that became RFC 7996, please see https://datatracker.ietf.org/doc/draft-iab-svg-rfc/.)
